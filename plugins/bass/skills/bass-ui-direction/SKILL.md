# BASS UI Direction

If CLI inspection is needed, resolve `../../scripts/bass-launcher.cjs` relative to this file and invoke it with Node.

Inspect the rendered product, existing components, tokens, and `DESIGN.md`. Then add or refresh one short `## Direction` section covering:

- aesthetic intent and what to avoid;
- information density and hierarchy;
- type scale and typography character;
- color roles, contrast, and surface treatment;
- motion purpose, duration character, and reduced-motion behavior.

Resolve conflicts with existing product evidence explicitly. Do not copy another vendor's skill text or create speculative design systems. Preserve an already selected direction. After implementation, verify the product's actual target viewports and reduced-motion behavior where applicable.
