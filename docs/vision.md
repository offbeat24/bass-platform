# Vision

BASS 는 AI가 사람을 대신하여 무제한으로 코드를 생성하는 자동 개발기가 아니다.
인간 감독형 소프트웨어 개발 런타임으로서 다음을 보장한다.

- 인간이 목적과 제품 판단을 담당한다.
- AI는 조사, 비판, 계획, 구현 후보 생성과 검증 보조를 담당한다.
- 기계적으로 확인 가능한 부분은 테스트와 평가기가 검증한다.
- 의미, 가치, 방향, 위험 수용과 최종 책임은 인간에게 남는다.
- 모든 작업은 사람이 실제로 읽고 이해하고 검토할 수 있는 크기로 제한한다.
- AI가 요구사항을 이해하지 못했을 때 임의로 추측하여 구현하지 못하게 한다.
- 프로젝트에서 얻은 교훈이 규칙, 테스트, 문서와 평가 기준으로 환류된다.

## 성공의 정의

BASS 의 성공은 AI가 혼자 많은 코드를 생성하는 것이 아니다.

> AI를 사용해 개발 속도와 탐색 능력을 높이면서도,
> 인간이 목적과 판단과 이해와 책임을 잃지 않는다.

## 전체 흐름

```text
Human intent
→ Environment investigation
→ Relentless but proportional clarification
→ Shared understanding
→ Short reviewable task definition
→ Risk and capability assessment
→ Appropriate model selection
→ Constrained implementation
→ Mechanical verification
→ Independent adversarial critique
→ Human judgment and approval
→ Execution and observation
→ Learning fed back into tests, rules, documents, profiles, and design specs
```
