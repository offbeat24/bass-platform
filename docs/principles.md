# Principles

| Principle | Runtime mechanism |
|---|---|
| Humans own purpose and risk | explicit risk and final judgment records |
| Agents investigate facts | repository inspection before CAPTURED is complete |
| Smallest accepted implementation | Ponytail or builtin simplicity, task scope lock |
| Verification follows risk | Fast, Standard, Hardened ExecutionPlan |
| Passing evidence is reused | affected diff fingerprint cache |
| Deletion does not become a redesign | automatic no-adjacent-work scope lock |
| Plugins are real capabilities | selected provider must be installed; no silent fallback |
| Handoff stays small | short AGENTS block and depth-proportional `.bass` records |
| Existing repositories stay authoritative | marker-only integration and no target runtime dependency |
